# Heatwave Watch

AI-powered heatwave early warning dashboard, written in C and compiled to WebAssembly. Data Structures Lab mini project.

**Live website:** https://heatwave-zeta.vercel.app/

## Files

- `heatwave.c`: the C source code with all the data structures
- `heatwave.wasm`: the C code compiled to WebAssembly
- `index.html`: the web dashboard
- `build_wasm.sh`: the command that builds the `.wasm` file
