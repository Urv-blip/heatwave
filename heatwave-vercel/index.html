Eight slots.
One loop.

New readings are written at in. The oldest is processed from out. When the end of the array is reached, the queue wraps around to the start. If every slot is taken, the next reading is rejected.

Step 2: Linked list

Newest first.

Each processed reading becomes a node added at the head. The list keeps the latest 10, and the oldest node is deleted from the end. Every box holds data and a pointer to the next.

Step 3: Priority queue

Worst first.

A reading in the caution range or higher raises an alert. A max-heap serves alerts by severity, not by arrival time. The root of the tree is always the hottest.

Where the risk level comes from

For every reading, heat_index_c() combines temperature and humidity with the standard Rothfusz formula. The larger of the air temperature and the heat index is the feels-like value. classify() then sets Safe below 35°, Caution up to 40°, Danger up to 45° and Extreme beyond that. It is a rule-based system, not machine learning.

Circular queue

A fixed array of 8 readings with head and tail indexes. Both move forward with (i + 1) % 8, so the array wraps around. cq_enqueue and cq_dequeue are O(1). A full queue rejects the reading (overflow), and an empty one reports underflow.

Linked list

Each node stores one observation and a next pointer. ll_insert_head is O(1). When the list passes 10 nodes, the program walks to the end and frees the last node, so memory never grows without limit.

Priority queue

A max-heap stored in an array, where the children of index i sit at 2i+1 and 2i+2. heap_push sifts the new alert up and heap_pop sifts the replacement down, both O(log n). Higher feels-like temperature wins; on a tie the older alert goes first.

Sorting and searching

Bubble and insertion sort take O(n²) comparisons, and quick sort takes about O(n log n) on average. Binary search needs the station table in alphabetical order and takes O(log n) steps. Linear search takes O(n).

How the page talks to C

The same heatwave.c compiles to a native web server or to WebAssembly. Either way the page calls one C function, api_dispatch(), which updates the data structures and returns JSON.
